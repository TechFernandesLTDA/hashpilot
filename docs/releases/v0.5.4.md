# v0.5.4 — descoberta, documentação e confirmação de carteira

Simplifica a entrada do README em português/inglês, destaca instalação e limitações, adiciona uma página pública bilíngue e um formulário de experiência externa. Capturas recentes da UI v0.5.3 usam telemetria real de uma RTX 3070; saldos, previsões, carteira e identificadores foram explicitamente ocultados. O vídeo v0.1.0 permanece identificado como histórico; não foi gerado vídeo novo.

Ações explícitas de iniciar GPUs pela interface pedem confirmação, com padrão Não, quando o destino efetivo é a carteira do autor. Considera overrides existentes por GPU no assistente. Cancelar preserva a configuração e não inicia o serviço. A carteira do autor continua padrão, como solicitado, e a contribuição opcional continua desativável. Esta confirmação da UI não é uma política universal de autorização: GPUs novas detectadas por um serviço já ativo continuam seguindo a configuração padrão documentada.

Adiciona material para revisão de segurança e métricas agregadas locais. Nenhum resultado externo foi inventado. A análise Microsoft do SRBMiner 3.8.1 permanece pendente; não foi concedida exceção ou restaurada quarentena nesta atualização.

Validação: 387 testes unitários; revisão dos resultados do agente Terra pelo agente principal; verificações de documentação, links locais da página, arquivos públicos e segredos. HashPilot é pré-lançamento; múltiplas GPUs continuam simuladas nos testes. Isso não constitui auditoria independente de segurança.
