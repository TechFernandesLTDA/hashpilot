# v0.5.13 — Eixos dos gráficos sem sobreposição

Os horários no rodapé dos gráficos eram criados a cada redesenho sem remover os anteriores. Durante uso prolongado, os textos se sobrepunham e a quantidade de objetos no canvas crescia continuamente.

A interface agora substitui os dois rótulos do eixo temporal em cada atualização, junto com a série e os demais elementos dinâmicos. O histórico armazenado, as medições e as configurações permanecem preservados.

Uma regressão usa um canvas Tcl/Tk real, sem exibir janela, para verificar que 100 redesenhos mantêm a quantidade de objetos constante e que os rótulos desaparecem quando não há amostras. A troca de interface não reinicia a mineração nem o serviço do rig.

O SRBMiner permanece na versão 3.8.4. Esta correção não introduz mineração dual nem altera clocks ou limites térmicos.
